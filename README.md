# Form Validation

A client-side form validation exercise built with vanilla JavaScript.

## Features

* Username validation

  * Required
  * Minimum 4 characters
* Email validation

  * Required
  * Must contain `@`
* Password validation

  * Minimum 8 characters
* Password confirmation

  * Must match the password
* Real-time validation while typing
* Visual error states for invalid fields
* Success message after successful submission

## Technologies

* HTML
* CSS
* JavaScript

## What I Practiced

* DOM manipulation
* Event listeners
* Form submission handling
* `preventDefault()`
* Functions and return values
* Conditional logic
* Dynamic CSS classes
* Input validation
